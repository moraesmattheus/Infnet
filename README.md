# Infnet App (Versão Acadêmica Aprimorada)

Aplicativo mobile nativo desenvolvido para o **Instituto Infnet**, focado em velocidade, usabilidade e suporte integral à rotina do estudante de Engenharia de Software e graduações de tecnologia.

---

## 🎯 Pilares do Projeto

1. **Ultra Fluido e Instantâneo:** Carregamento em menos de 1 segundo com cache offline local, eliminando a lentidão do portal web tradicional.
2. **Aulas e Zoom Integrados:** Acesso direto à sala ao vivo do dia (Zoom/Teams) com 1 toque, sem caçar links em fóruns.
3. **Anotações Inteligentes de Aula:** Caderno digital acoplado a cada aula e disciplina, salvo no celular.
4. **Gestão de Prazos (TPs e ATs):** Notificações push automáticas no celular 48h e 24h antes do encerramento das entregas.
5. **Manual do Aluno com RAG (IA):** Assistente inteligente que responde dúvidas instantâneas sobre regras acadêmicas, critérios de avaliação, cálculo de média e calendário de provas.

---

## 🛠️ Stack Tecnológica

- **Frontend:** React Native com Expo (TypeScript)
- **Roteamento:** Expo Router (File-based routing)
- **Armazenamento Offline:** AsyncStorage / SQLite
- **Notificações:** Expo Notifications
- **IA / RAG:** Integração com motor RAG local / API do Manual do Aluno
